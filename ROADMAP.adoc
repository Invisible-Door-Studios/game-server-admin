= Game Server Admin (GSA) Roadmap
:author: Jonathan D.A. Jewell
:revdate: 2026-10-18

== Current State

GSA is a game-server discovery, configuration-management, and administration tool.
Its existing 18-profile registry is a legacy compatibility inventory, not a
universal server contract. 96% complete (v0.9.0). Gossamer GUI + Zig FFI + Idris2
ABI + VeriSimDB backing store.

Key capabilities delivered:

* 40 exported FFI symbols (Zig 0.15.2, libgsa.so)
* 14 Zig source modules, including `profile_contract.zig` (draft fixture validator; not a public FFI surface)
* Protocol fingerprinting (8 protocols, 20+ known ports)
* Config parsing (8 formats: XML, INI, JSON, ENV, YAML, TOML, Lua, KV)
* 18 existing legacy game profiles (`profiles/*.a2ml`); current standards prohibit new A2ML profiles
* Draft JSON profile/config validator and SOP design fixture (test-only; no live adapter, ABI, GUI, or deployment integration)
* 8 Gossamer GUI panels + 9 panel clades
* VeriSimDB on 2 ports (main 8090, backup 8091 for game saves)
* Legacy A2ML serialisation, parsing, and config diff (compatibility path only; not a new profile contract)
* Groove voice alerting via .well-known
* Server actions via Podman/Docker/systemd
* Secret redaction for config fields marked secret in existing A2ML output; this is not a session-data privacy policy
* Chainguard Wolfi containers with quadlets
* Idris2 ABI with 18 result codes
* Desktop entry and icon assets (SVG + PNG)
* Steam Web API client (vanity->Steam64 resolution, player summary, ownership check)
* Nexus Setup GUI -- 7-step provisioning wizard (profile -> Steam resolve -> config -> SSH target -> file staging -> provision -> verify)
* CryoFall container stack (Containerfile, Quadlet, schema-driven provisioner, self-heal watchdog)
* HTTP capability gateway (Phase 11) -- capability-scoped REST surface over the FFI
* Illustrated wiki + reference docs (Phase 12)
* AffineScript TEA interface (`src/ui/tea/gsa_gui.affine`) — profile-registry-driven admin UI over libgsa; the draft JSON validator is not wired into it

Test suites:
* Zig unit tests: 94, passing
* Integration tests: 41 tests, passing
* Smoke tests: 5, passing
* E2E smoke tests: 8/8 against live VeriSimDB
* Gossamer chain: parser gaps CLOSED (let/let! verified 2026-07-07); remaining failure is env-only (libgossamer.so unbuilt — needs GTK dev libs)
